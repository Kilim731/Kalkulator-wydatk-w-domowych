# Kalkulator-wydatk-w-domowych

Program napisany w c#
Pozwala na zapisywanie na czas działania programu wydatków domowych i sprawdzanie na co przeznaczane jest najwięcej środków.
Program zezwala na sumowanie wszystkich wydatków

Niestety program nie pozwana jeszcze na poprawianie wydatków ani usuwanie błędnie dodanych wydatków. Program także nie zapisuje poprzedniej sesji, co nie pozwala na przechowywanie wydatków w osobnych plikach.
